# Website-Traffic-Dashboard-1
An interactive Website Traffic Analysis Dashboard built using Python, Pandas, Matplotlib, and Jupyter Notebook. This project analyzes website traffic data to understand user behavior, engagement rates, sessions, traffic sources, and user activity by hour. It uses data cleaning, grouping, and visualization techniques to present meaningful insights through colorful charts and graphs.

**Purpose:** To analyze website performance and understand user engagement using data analysis and visualization.

**Technologies Used:** Python, Pandas, Matplotlib, Jupyter Notebook.

**Key Features:**
- Website traffic analysis
- Total users by channel
- Average engagement time by channel
- Engagement rate distribution
- Engaged vs. non-engaged sessions
- Traffic analysis by hour and channel

**Project Type:** Data Analytics and Data Visualization.
